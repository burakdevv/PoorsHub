## 🔥 Neden PoorsHub?

* 🎨 **Modern & Şık Tema:** Göz yormayan koyu mor/neon renk paleti ve yuvarlatılmış hatlara sahip özel UI tasarımı.
* 🔍 **Anlık Arama Motoru:** İstediğin hileyi veya özelliği saniyeler içinde bulmanı sağlayan dinamik arama çubuğu.
* 👥 **Gelişmiş Oyuncu Yönetimi:** Sunucudaki oyuncuları listeleyin; tek tıkla Işınlanın (`TP`), Kameraya Alın (`See`), Kostüm Kopyalayın (`Copy`) veya Trol Özelliklerini (`Bang`) kullanın.
* 💻 **Dahili Executor & Terminal:** Hub içerisinden ayrılmadan kendi özel Lua kodlarınızı test edin ve çalıştırın.
